# ✈️ What is AERO-SENTINEL?

**AERO-SENTINEL** is a predictive engine-health platform designed for **MALE (Medium Altitude Long Endurance) UAV aero piston engines**.

Instead of waiting for an engine parameter to cross a critical threshold, AERO-SENTINEL continuously combines:

> **Engine Telemetry + Secure Communication + Digital Twin + AI + Fuzzy Logic + Degradation Analysis + RUL + Mission Risk**

to provide an early indication of abnormal behaviour and support maintenance decisions.

The system creates a **virtual representation of the engine**, synchronizes it with telemetry, analyses its current condition, tracks degradation, estimates Remaining Useful Life (RUL), and evaluates whether the planned mission introduces additional risk.

Traditional monitoring can answer:

> **"Is the engine abnormal right now?"**

AERO-SENTINEL aims to answer a larger set of questions:
